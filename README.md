**Course:** COS 201 – Computer Programming I  
**Programme:** Software Engineering

### Objective
To understand the Java development environment, write Java programs, compile and execute them, use output statements and comments, and identify and correct basic programming errors.

### Tools Used
- Java Development Kit (JDK)
- Visual Studio Code
- Git
- GitHub
- Windows CMD

### Files
- `week02/HelloWorld.java`
- `week02/PrintExample.java`
- `week02/CommentsExample.java`
- `week02/ErrorExample.java`

### How to Run
Open CMD inside the `week02` directory.

Compile and run each file using:

```cmd
javac HelloWorld.java
java HelloWorld

javac PrintExample.java
java PrintExample

javac CommentsExample.java
java CommentsExample

javac ErrorExample.java
java ErrorExample
```

### Learning Outcomes
- Understanding the Java development environment.
- Writing, compiling and executing Java programs.
- Understanding the difference between `print()` and `println()`.
- Using single-line and multi-line comments.
- Identifying and correcting basic syntax errors.
